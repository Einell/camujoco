# 渲染基线验证结果

2026-10-19，在当前机器完成首个渲染交付物。当前机器实际显卡为 NVIDIA GeForce RTX 4060 Laptop GPU 8GB，驱动 590.48.01；不是需求中指定的 RTX 5060。

| 检查 | 结果 |
| --- | --- |
| 后台渲染，预热 10 秒、测量 60 秒 | 每路 30.00 FPS；渲染 P95 27.22 ms |
| 真实 Qt 桌面窗口，预热 10 秒、测量 60 秒 | 每路 29.85 FPS；渲染 P95 22.90 ms |
| Qt 桌面 UI 邮箱丢帧 | 0 |
| 桌面运行物理实时率 | 0.999 |
| 桌面进程峰值 RSS | 559 MiB |
| 软件渲染回归测试 | 9 项通过 |
| NVIDIA GPU 回归测试 | 9 项通过，1.05 秒 |
| 截图检查 | 全局视图和三路相机画面正常，状态栏可见 |

两次性能测试均为三路 1280×720 RGB uint8 和深度 float32，同时额外渲染全局视图。两次测量不同时运行；后台与桌面结果差异来自运行时负载，不能解释为界面提升了渲染速度。P95 仅覆盖渲染，不是完整端到端延迟。

## 已实现

- 内置桌面场景和受控摆杆运动。
- 三路独立相机与全局视图。
- RGB/深度预览切换，暂停、继续和重置。
- 全局观察视角旋转、缩放。
- 单工作线程拥有 OpenGL 上下文；不可变图像批次和有界最新帧邮箱。
- 后台/桌面测量工具，以及真实渲染、深度精度、复位、资源重建和统计回归测试。

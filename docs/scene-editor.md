# 场景与相机编辑

启动 `./run.sh` 后，左侧 Scene properties 显示物体层级和三台预览相机。选择条目，修改数值并点击 Apply，仿真自动暂停。

- XYZ 单位为米；旋转为归一化 wxyz 四元数。普通物体位姿相对父 body，自由关节物体相对世界。编辑物体会更新初态、重置整个仿真并更新运行/模型标识；Reset 回到编辑后的初态。
- 相机位姿相对 Camera parent。选择 world 表示世界固定，选择物体表示挂载；输入数值以新父坐标系解释，不自动保持旧世界位姿。
- 相机使用光学坐标：X 向右、Y 向下、Z 向前。可调整 width/height、fx/fy/cx/cy、near/far；新图像与标定参数一起生效。
- 选择目标物体并点击 Aim camera at body 可对准其当前原点。
- 拖动相机画面可沿相机局部 XY 平移，滚轮沿光轴前后移动。全局视图独立旋转/缩放，不改变输出相机。
- Camera frustums 在全局视图绘制透视线框，仅用于方向/视场提示，显示长度按场景大小截取，不代表完整远裁剪范围，也不进入相机 RGB 或深度。
- Float view 打开独立窗口，关闭后回到原面板；浮动或隐藏预览不会停止相机数据输出。关闭主窗口时全部预览随之关闭。

应用相机位姿编辑会将源模型的 tracking/target 模式改为相对所选父 body 固定；未编辑的跟踪相机在追加时保留原模式。追加模型保留已应用的物体初态和相机编辑，打开新场景则替换它们。

可用 Save project 将当前编辑初态持久保存。已支持返回编辑、单步和保存当前姿态为初态，见 [仿真操作](simulation.md)。项目保存已实现；线程内数据订阅与控制入口见 [数据接口](data-control-api.md)，真实算法与策略仍属于后续阶段。模型关节角编辑尚无独立面板；这里编辑的是 body 坐标系。

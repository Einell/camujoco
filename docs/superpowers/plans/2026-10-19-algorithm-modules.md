# 算法模块接入

已确认范围：保留场景、三相机、静态/动态和项目功能，以 Python 接口扩展位姿算法。

实现步骤：
1. 定义 PoseEstimator 的 start(cancel)、estimate(observation)、close 协议和不可变状态/结果。
2. ModuleManager 注册工厂，每次启动创建新实例，在独立线程执行；输入和输出订阅各限制两批，异常隔离。
3. 按输入 FrameStamp 校验输出，利用已有 DataAPI 原帧真值历史评估，过期结果标记 unavailable。
4. SDK 提供 lab.modules，桌面提供模块选择、启动停止、状态及带帧标识的误差面板。
5. 固定姿态演示验证连接，无真实算法或真值输入；添加生命周期、慢算法、SDK 和 Qt 集成测试，跑全量回归。

线程采用协作取消，无法强制终止任意第三方 Python 代码；需要硬超时的算法应通过子进程适配。界面展示独立结果，不将延迟结果叠加到当前图像。

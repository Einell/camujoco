# 腕部相机评测实现计划

目标：在 Camera Lab 中公平比较 Revo3 腕部安装候选，保留现有桌面和算法接口。

用户已授权补齐必要功能。已确认Revo3右手、单相机；真实机械臂、镜头、支架和任务轨迹尚待提供；官方 Revo3 右手模型只用于验证工具，不能代替用户整机结论。

选择：使用既有 SDK 的离线逐候选运动学回放，不将24台相机同时加载，也不以动态策略执行替代第一轮几何筛选。相较纯手工截图，可复现逐阶段统计；相较立即闭环训练，不引入策略分布变化。

- [x] `project/importer.py`、`sdk.py`、`runtime.py`：支持把模型挂到指定父 body，验证父节点并保留旧场景的事务式导入；测试运动层级。
- [x] `sim/replay.py`：复制状态/关节描述，验证完整 qpos 与单位四元数、有限时刻，再运动学赋值并 mj_forward；SDK 提供 state/seek，seek 进入暂停、新run并清空旧控制。测试原子失败与相机随腕运动。
- [x] `evaluation.py`：基于同帧观测与真值的局部表面关键点投影和深度遮挡检测，区分出框/遮挡/近距无效；按明确采样区间统计可见率、共同可见率、最长失视。明确理想深度不是实测有效深度。
- [x] `experiments/wrist.py`：配置驱动候选与完整状态序列回放、逐帧CSV/分阶段JSON和示例图；同一输入逐候选，最多三路输出。可执行命令与官方模型示例，不编造真实任务成功率。
- [x] 解析测试、真实渲染遮挡测试、官方模型冒烟与全量回归；代码审查；给出三类任务采集、24候选粗筛、角度细筛、双目互补及真实验证的具体步骤。

限制：当前针孔理想渲染不模拟150度鱼眼畸变、对焦/运动模糊或真实深度失效；碰撞必须有相机/支架碰撞几何。没有这类资产时不得输出“安装安全”。
